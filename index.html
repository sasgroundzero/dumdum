Phone

Make this phone dumb

About 15 minutes, once. Nothing gets deleted and no Screen Time settings are changed. One switch turns it all on and off.

Put DumDum on your Home Screen

  1. Open this page in Safari.
  2. Tap Share → Add to Home Screen → Add.
  3. Open DumDum from the new icon from now on.

Choose black and white

Settings → Accessibility → Display & Text Size → Color Filters

Turn on Color Filters, pick Grayscale, then turn Color Filters off again. Dumb mode will switch it on for you.

Pick your one directions app

The Directions button opens this one.

Connect your calendars

Settings → Apps → Calendar → Calendar Accounts → Add Account

  1. Choose Google, Microsoft Exchange or Outlook.com and sign in. On older iPhones the path is Settings → Calendar → Accounts.
  2. Make sure the Calendars switch is on for each account.

The Calendar button opens the iPhone's Calendar, which stays in sync with those accounts both ways. The Clock button opens the iPhone's Clock for alarms, timers and the stopwatch.

Make the shuffle-only Music button

Works with Apple Music or songs synced to the Music app.

  1. Open the Shortcuts app and tap +.
  2. Add the action Play Music.
  3. Tap the word Music in the action and choose a playlist, or your whole library.
  4. Tap the arrow on the action and set Shuffle to Songs.
  5. Name the shortcut exactly DumDum Shuffle and tap Done.

The Music button now starts a shuffle. Pause and skip from the Lock Screen or your headphones.

Make one plain Home Screen page

  1. Drag DumDum, Phone, Messages, Mail, Calendar, Clock, Safari and your directions app onto one page of their own.
  2. Leave your other pages as they are. Dumb mode hides them and brings them back.

Create the Dumb mode

Settings → Focus → + → Custom

  1. Name it exactly Dumb.
  2. People: allow notifications from everyone, so calls and texts still arrive.
  3. Apps: allow only Phone, Messages, Mail, Calendar and Clock.
  4. Customize Screens → Home Screen: tick only the plain page from the last step.
  5. Options: turn on Hide Notification Badges.

This uses Focus only. It does not touch Screen Time, Downtime or any app limits already on the phone.

Make Dumb mode turn the screen grey

Shortcuts → Automation → +

  1. Choose Dumb, then When Turning On and Run Immediately.
  2. Add three actions, each set to On: Set Color Filters, Set Reduce Motion, Set Reduce Transparency. Tap Done.
  3. Make a second automation the same way with When Turning Off and the three actions set to Off.

Leaving Dumb mode now puts the screen back to normal by itself.

Send other apps back to the Home Screen

Shortcuts → Automation → + → App

  1. Tap Choose and tick every app you want kept out of reach. Leave the eight DumDum uses unticked.
  2. Choose Is Opened and Run Immediately.
  3. Add Get Current Focus.
  4. Add If. Tap Current Focus, choose Name, set it to is and type Dumb.
  5. Inside the If, add Go to Home Screen. Tap Done.

In Dumb mode those apps now close as soon as they open. Outside Dumb mode they work as usual. Tick newly installed apps here when you add them.

Make the on and off switch

  1. In Shortcuts, tap + and add Set Focus. Set it to turn Dumb On. Name it exactly DumDum On.
  2. Make a second one that turns Dumb Off. Name it exactly DumDum Off.

The two buttons at the bottom of this page run them. You can also switch Dumb mode from Control Centre → Focus.

Dumb mode

Works once the setup above is done.

On: other pages hidden, other apps bounce shut, notifications quiet, screen grey. Off: everything is back exactly as it was.
